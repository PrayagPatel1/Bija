# Bija Documentation

 This is the official documentation for Bija, a linear algebra library that supports small vectors and matrices allocated on the stack.
# vec2df_add

**Description**: Sums two Vec2D_f vectors.

 **Parameters**: Vec2D_f vec1 |  Vec2D_f vec2

**Return**: The sum of two Vec2D_f vectors as a Vec2D_f vector.
# vec2df_sub

**Description**: Difference two Vec2D_f vectors.

 **Parameters**: Vec2D_f vec1 |  Vec2D_f vec2

**Return**: The difference of two Vec2D_f vectors as a Vec2D_f vector.
